About Post-Quantum Cryptography

Why PQC Matters

Quantum computers pose a significant threat to current cryptographic systems. Algorithms like RSA and ECC that secure today's internet could be broken by sufficiently large quantum computers.

Post-quantum cryptography refers to cryptographic algorithms that are thought to be secure against an attack by a quantum computer.

PQC-AES Implementation

This demonstration uses AES-256 in GCM mode with SHA3-256 for key derivation, simulating a post-quantum cryptography approach.

While AES itself isn't post-quantum, this implementation demonstrates the principles of quantum-resistant encryption using standardized algorithms.

Flask Backend Integration

server.py 
from flask import Flask, jsonify, request
from Crypto.Cipher import AES
from Crypto.Hash import SHA3_256
from Crypto.Random import get_random_bytes
import base64

app = Flask(__name__)

@app.route('/api/generate_keys', methods=['POST'])
def generate_keys():
    private_key = get_random_bytes(32)
    public_key = SHA3_256.new(private_key).digest()
    return jsonify({
        'public_key': base64.b64encode(public_key).decode('utf-8'),
        'private_key': base64.b64encode(private_key).decode('utf-8'),
        'algorithm': 'PQC-AES-SIMULATION'
    })

@app.route('/api/encrypt', methods=['POST'])
def encrypt_message():
    data = request.json
    public_key = base64.b64decode(data['public_key'])
    message = data['message'].encode('utf-8')
    
    key = public_key[:32]
    cipher = AES.new(key, AES.MODE_GCM)
    ciphertext, tag = cipher.encrypt_and_digest(message)
    
    return jsonify({
        'ciphertext': base64.b64encode(ciphertext).decode('utf-8'),
        'nonce': base64.b64encode(cipher.nonce).decode('utf-8'),
        'tag': base64.b64encode(tag).decode('utf-8'),
        'encrypted_message': base64.b64encode(ciphertext).decode('utf-8')
    })

@app.route('/api/decrypt', methods=['POST'])
def decrypt_message():
    data = request.json
    ciphertext = base64.b64decode(data['ciphertext'])
    private_key = base64.b64decode(data['private_key'])
    nonce = base64.b64decode(data['nonce'])
    tag = base64.b64decode(data['tag'])
    
    key = SHA3_256.new(private_key).digest()[:32]
    cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
    decrypted = cipher.decrypt_and_verify(ciphertext, tag)
    
    return jsonify({
        'message': decrypted.decode('utf-8'),
        'status': 'success'
    })

if __name__ == '__main__':
    app.run(ssl_context=('cert.pem', 'key.pem'))
